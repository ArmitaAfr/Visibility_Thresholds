How many strokes does a concept need?

A CLIPDraw drawing is replayed one stroke at a time, most important stroke first. At 8, 16, 32, 64, 128 and 256 strokes, SigLIP checks whether it picks the right word, and Florence describes what it sees. Its visibility threshold is the first stroke count where SigLIP recognizes it and keeps recognizing it at every larger count.

These drawings and judge scores are hand-made examples to show the idea. Load the JSON exported from Colab to replay real CLIPDraw runs.

File format for real runs

The Colab script export_for_demo.py writes this. A file can hold one concept or a list of them. Strokes are listed most important first. Each stroke is a diffvg cubic path: 3k + 1 points in canvas pixels, with a width and an RGBA colour from 0 to 1.
